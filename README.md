# 화제 방지 멀티탭

화제 예방을 위한 콘센트

## 문제

멀티탭 사용 중 화재 발생과 노후화된 멀티탭 등을 관히, 처리하는데 어려움을 겪는다. 멀티탭을 사용하는 사람들 중 10명 중 9명이 비슷한 문제를 겪는다고 답했다.

## 사용 부품 및 기술

ESP32, ky-026(불꽃 감지 센서), GP2Y1010AU0F(먼지 감지 센서), ACS712 5A(홀 효과 전류 센서), Esp 보드를 이용한 블루투스, 와이파이 통신, Blynk IOT (스마트 폰 앱/ 웹 대시보드), 브래드 보드, 점퍼선, 릴레이 모듈, 1채널 릴레이 모둘 5V

## 시스템 구성

입력(센서) -> 판단(코드) -> 출력(동작) -> 표시(스마트 폰 앱, 웹 대시보드)

## 실행 방법

1. 센서 및 부품들을 배선도 대로 연결합니다.
2. 코드를 esp32 보드에 업로드 합니다.
3. 핸드폰 앱을 이용해서 esp32 보드와 연동
4. 전원을 연결한 후 과전류(저전압)를 흘려보내 일부러 아크와 발열을 올린다.
5. 연결된 어플로 화재 경고 알림이 오며 전원이 차단됨.
