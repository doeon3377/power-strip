# 화제 방지 멀티탭

멀티탭 사용 중 발생하는 화재 위험과 관리 어려움을 해결하기 위해, 과열·먼지·전류 이상을 감지해 자동으로 전원을 차단하고 스마트폰 연동으로 안전 상태와 사용시간을 관리하는 스마트 안전 멀티탭

## 문제

멀티탭 사용 중 화재 발생과 노후화된 멀티탭 등을 관히, 처리하는데 어려움을 겪는다. 멀티탭을 사용하는 사람들 중 10명 중 9명이 비슷한 문제를 겪는다고 답했다.

## 사용 부품 및 기술

ESP32, ky-026(불꽃 감지 센서), GP2Y1010AU0F(먼지 감지 센서), ACS712 5A(홀 효과 전류 센서), Esp 보드를 이용한 블루투스, 와이파이 통신, Blynk IOT (스마트 폰 앱/ 웹 대시보드), 브래드 보드, 점퍼선, 릴레이 모듈, 1채널 릴레이 모둘 5V

## 시스템 구성

입력(센서) -> 판단(코드) -> 출력(동작) -> 표시(스마트 폰 앱, 웹 대시보드)

## 실행 방법

1. 센서 및 부품들을 배선도 대로 연결합니다.
2. 코드를 esp32 보드에 업로드 합니다.
3. 핸드폰 앱을 이용해서 esp32 보드와 연동
4. 전원을 연결한 후 과전류(저전압)를 흘려보내 일부러 아크와 발열을 올린다.
5. 연결된 어플로 화재 경고 알림이 오며 전원이 차단됨.

## 막혔던 문제와 해결

문제 1 (하드웨어): 상용 220V 전원을 시제품에 직접 연결할 경우 감전 위험 및 과전류·아크 발생 시 제어 보드가 파손될 우려가 있었음

해결: 상용 220V 직결 방식을 배제하고, 아두이노/ESP32와 5V~12V 릴레이 모듈을 적용해 저전압 제어 회로와 고전력 부하 회로를 물리적으로 절연 분리하여 안전성을 확보함   

문제 2 (하드웨어/소프트웨어): 온도·전류·먼지·불꽃 등 다수의 센서를 동시에 구동할 때 아날로그 신호 노이즈와 신호 간섭으로 인해 MCU가 리셋되거나 릴레이가 오동작하는 현상이 발생함   

해결: 모든 기능을 한 번에 연결하지 않고 ①과열·과전류 차단, ②불꽃·먼지 감지 보강, ③스마트폰 통신 연동의 3단계로 기능을 분리해 순차 검증하며 배선 및 필터링을 보완하여 오동작을 0회로 줄임   

## 배운 점 — 개인 회고 한 줄

- 김도언 - 사용자 니즈 분석을 바탕으로 화재 방지 멀티탭의 핵심 기능 정의와 서비스 흐름을 체계화하는 역량을 키움
- 문도균 - 시장 경쟁력 분석 및 비즈니스 모델 구체화를 통해 제품의 실효성과 확장성을 검증하는 과정을 경험함 
- 도현승 - 저전압 릴레이 회로 설계와 단계별 검증을 거치며 전기 안전과 신뢰도 높은 제어 시스템 구축의 중요성을 체득함
- 민정규 - ESP32 펌웨어 구현과 센서 데이터 필터링을 통해 다중 센서 간 신호 간섭을 효과적으로 해결하는 법을 배움
